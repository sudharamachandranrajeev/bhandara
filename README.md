# Bhandara

**Bhandara** (भण्डार, "storeroom") is a cross-platform storage monitor for Linux (Omarchy), Windows and Android.

## Modules

- **Bhandara Bar**: Omarchy status bar widget showing a disk usage ring and a storage panel.
- **Bhandara Darshana** (दर्शन, "view"): a fluid, modern storage dashboard.
- **Bhandara Swasthya** (स्वास्थ्य, "health"): disk health and SMART status.
- **Bhandara Suchi** (सूची, "index"): system-wide file index, stats and safe file operations.

Built with Rust and Tauri 2. Windows gets a tray icon with a quick-view flyout.

## Status

Early development. Nothing is ready to install yet.
